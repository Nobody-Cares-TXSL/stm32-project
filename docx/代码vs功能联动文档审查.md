## 五、各模块缺失项汇总

### 5.1 温湿度 (th_view.c)
- [ ] 升温速率计算逻辑（每 2 秒记录，(当前-上次)/2）
- [ ] 升温速率显示（替换或追加到湿度位置）
- [ ] 温度阈值判定（30/40/60 四级）
- [ ] 连续读取失败计数（10 次故障提示）

### 5.2 烟雾 (smoke_view.c)
- [ ] 显示 ADC 原始值而非百分比（或同时显示）
- [ ] 报警等级判定（200/800/2000 三级阈值）
- [ ] 防误报：连续 3 次采样稳定达标

### 5.3 火焰 (flame_view.c)
- [ ] 两路取最大值逻辑
- [ ] 单路异常偏低自动丢弃
- [ ] 阈值改为 100/300/800 三级（当前 3000 反转逻辑不符）
- [ ] 报警等级判定

### 5.4 光敏 (light_view.c)
- [ ] 白天/天黑判定（阈值 800）
- [ ] 天黑时联动灯带基础白光（无火情时）
- [ ] 故障检测（10 次无变化）

### 5.5 风扇 (fan_view.c)
- [ ] 自动模式：按报警等级联动 30%/60%/100%
- [ ] 助燃互斥：升温二级+烟雾低时不启动
- [ ] 仅室内启用标志

### 5.6 蜂鸣器 (PA4)
- [ ] 整个模块缺失：驱动 + 视图 + 分级鸣响
- [ ] 分级：静音/5秒断续/1秒断续/持续长鸣
- [ ] 消音按键联动

### 5.7 灯带 (ledstrip_view.c)
- [ ] 基础白光模式（天黑常亮）
- [ ] 火情优先级自动切换（覆盖光敏照明）
- [ ] 消音联动（15 秒熄灭）

### 5.8 水泵 (pump_view.c)
- [ ] 三种状态：停机/待机预加压/全速抽水（当前仅 ON/OFF）
- [ ] 故障状态显示
- [ ] 30 分钟保护定时器
- [ ] 自动模式：按报警等级联动

### 5.9 WiFi 通信 (PA2/PA3)
- [ ] 整个模块缺失
- [ ] USART2 驱动 + AT 指令通信
- [ ] 5 秒周期上报 + 事件即时上报
- [ ] 断连检测 + 本地缓存 + 恢复补传

### 5.10 中央联动引擎（核心缺失）
- [ ] 报警等级状态机（0/1/2/3 四级）
- [ ] 三传感器组合判定逻辑
- [ ] 防误报采样计数器
- [ ] 消音 15 秒倒计时
- [ ] 报警降级 10 秒稳定判定
- [ ] 跨模块输出调度（蜂鸣器/灯带/风扇/水泵/WiFi）

## 六、实现优先级

> 策略：先让每个模块独立采集、阈值判定、显示到位，最后写中央联动引擎("接线")。

| 顺序 | 模块 | 工作量 | 理由 |
|------|------|--------|------|
| 1 | 蜂鸣器 (PA4) | 小 (新建驱动+视图) | PA4 已分配，最简单的输出模块 |
| 2 | 温湿度升级 | 中 | 加升温速率计算+阈值判定，改显示 |
| 3 | 烟雾升级 | 小 | 加阈值分级判定 (200/800/2000) |
| 4 | 火焰升级 | 小 | 改阈值 (100/300/800)、取最大值逻辑 |
| 5 | 光敏升级 | 小 | 加白天/天黑判定 (阈值 800) |
| 6 | 灯带升级 | 中 | 加基础白光模式、火情优先级预埋接口 |
| 7 | 水泵升级 | 中 | 加停机/预加压/全速三状态 |
| 8 | 风扇升级 | 小 | 加自动模式联动预埋接口 |
| 9 | WiFi 通信 | 大 (新建驱动) | USART2 驱动+AT 指令，独立于联动 |
| 10 | 中央联动引擎 | 大 | 报警状态机+跨模块调度，最后做 |
