| 电压 | 供电对象 |

## 二、项目架构概述

### 2.1 架构模式

**Superloop（超级循环）+ 菜单驱动 + 中央联动引擎**，无 RTOS。主循环每 10ms 执行一帧。

```
                    ┌──────────────────────────────────────┐
                    │           main.c  (Superloop)         │
                    │   joystick_event()  →  menu_handle()  │
                    │                     →  alarm_tick()    │
                    │                     →  delay_ms(10)   │
                    └─────────┬──────────────────┬───────────┘
                              │                  │
                ┌─────────────▼─────────┐  ┌─────▼──────────────────────┐
                │  menu.c  菜单驱动框架  │  │  alarm.c  中央联动引擎      │
                │  8 个模块视图分发      │  │  采集→等级判定→执行器调度    │
                └─────────────┬─────────┘  └──┬────────────────┬──────────┘
                              │               │                │
                    ┌─────────▼──────────┐    │                │
                    │  视图层 *_view.c    │◄───┘                │
                    │  (th/smoke/flame/   │                     │
                    │   light/fan/pump/   │                     │
                    │   beep/ledstrip)    │                     │
                    └─────────┬──────────┘                     │
                              │                                 │
              ┌───────────────▼─────────────────────────────────▼──────────┐
              │              驱动层  (传感器  +  执行器)                      │
              │   dht · smoke · flame · light   │   fan · pump · beep · ledstrip │
              └───────────────┬──────────────────────────────────────────────┘
                              │
              ┌───────────────▼──────────────────────────────────────────────┐
              │   平台/工具层   io · usart · lcd · delay · sys                 │
              └──────────────────────────────────────────────────────────────┘
```

### 2.2 核心文件分层

| 层 | 文件 | 职责 |
|----|------|------|
| **平台/工具** | `io.c` | 统一外设初始化（GPIO/EXTI/NVIC/ADC/TIM/USART） |
| | `usart.c` | USART1 调试串口 + `printf` 重定向 |
| | `lcd.c` / `lcd_ui.c` / `lcdfont.h` | LCD 底层绘图 / 高层 UI / 字库 |
| | `delay.c` / `sys.c` | 延时 / 位带操作 |
| **传感器驱动** | `dht.c` | DHT11 温湿度（双路单总线） |
| | `smoke.c` | MQ-2 烟雾（AO + DO） |
| | `flame.c` | KY-026 火焰（双路 AO + DO） |
| | `light.c` | 光敏（AO + DO） |
| **执行器驱动** | `fan.c` | 风扇 PWM（PB0 / TIM3_CH3） |
| | `pump.c` | 水泵继电器（PA1 GPIO） |
| | `beep.c` | 蜂鸣器（PA4 GPIO） |
| | `ledstrip.c` | WS2812B 灯带（PC12 + PC11，bit-bang） |
| **中央引擎** | `alarm.c` | 报警状态机 + 数据聚合 + 执行器调度 |
| **菜单框架** | `menu.c` | 菜单项表 + 视图分发 |
| **视图层** | `*_view.c`（8 个） | 各模块 LCD 显示/控制界面 |

### 2.3 数据流

```
传感器原始数据（ADC/DHT/GPIO）
        │
        ▼
alarm.c  数据聚合 + 节流缓存（100ms/2s）
        │
        ├──→ alarm_eval_levels()  阈值判定 → cur_level（0/1/2/3）
        │
        └──→ alarm_dispatch_actuators()  按等级联动执行器
                │
                ├── 风扇：L1=30%  L2=60%  L3=100%
                ├── 蜂鸣器：L1=5s间歇  L2=1s间歇  L3=长鸣
                ├── 灯带：L0=光敏照明  L1=绿闪  L2=蓝闪  L3=红闪
                └── 水泵：L3=全速抽水
```

### 2.4 串口通信

| | USART1 | USART2 |
|---|--------|--------|
| 引脚 | PA9(TX) / PA10(RX) | PA2(TX) / PA3(RX) |
| 波特率 | 9600 | — |
| 用途 | `printf` 调试 log（sscom 查看） | 预留 |

### 2.5 菜单系统

主菜单 8 个模块视图，摇杆上下移动光标、按下 SW 进入视图、DOWN 返回。新增模块只需写 `xxx_view.c/h`（enter/tick/on_event 三件套），在 `menu_items[]` 加一行即可，框架零改动。

## 三、开发环境与工具

| 工具 | 版本 | 用途 | 说明 |
|------|------|------|------|
| **Keil uVision5** | MDK-ARM 5.x | IDE | 代码编写、编译（armcc）、链接、生成 HEX 文件；支持 SWD 在线调试 |
| **mcuisp** | — | ISP 烧录 | 通过 USART1（PA9/PA10）串口下载 HEX 到 STM32 Flash；需设置 BOOT0=1, BOOT1=0 进入 ISP 模式 |
| **sscom** | — | 串口调试 | 通过 USART1（9600 baud）查看 `printf` 调试输出 log |
| **STM32 标准外设库** | V3.5 | 外设驱动 | CMSIS + StdPeriph_Driver，路径 `~/stm32_std_lib/`，非 HAL/LL |
| **C 语言标准** | C17 | 编译标准 | 源文件使用 GB2312 编码（Keil 默认 GBK 兼容） |


| 模块 | 引脚 | 功能 | 备注 |
|------|------|------|------|
| LCD | PB4-PB9 | SPI（SCL/SDA/RES/DC/CS/BLK） | 128×128 全彩 |

## 五、注意事项

1. **MQ-2 预热**：首次使用需预热 24 小时以上，日常上电预热 2-5 分钟，否则 AO 值漂移
2. **ADC 电平安全**：MQ-2 为 5V 模块，AO 输出 0-5V，必须经电阻分压（2kΩ+3kΩ）降至 0-3V 再进 STM32 ADC 引脚，否则烧毁引脚
3. **WS2812 时序**：GPIO bit-bang 模拟，发送期间关全局中断，72MHz 下 NOP 微调
4. **DHT11 读取**：微秒级单总线时序，读取期间关中断
5. **共地**：所有模块 GND 必须与 STM32 共地
6. **烧录与调试引脚**：PA9/PA10（USART1）、PA13/PA14（SWD）勿挪作他用
