# 功能联动文档

> 社区智能消防烟温联动监测终端 - 各模块采集阈值、报警等级判定、跨模块联动规则

---

## 一、报警等级定义

| 等级 | 名称 | 触发条件 | 延时 |
|------|------|----------|------|
| 0 | 正常 | 所有参数均在正常区间 | - |
| 1 | 一级预警 | 单项或多项达一级阈值 | 连续 3 次采样（6 秒）稳定达标 |
| 2 | 二级预警 | 多项达二级阈值 | 连续 3 次采样（6 秒）稳定达标 |
| 3 | 三级确认火警 | 三项同时达三级，或两项严重超标 | **无延时，瞬时触发** |

**严重超标速判**：烟雾 > 2500 且温度 > 55，直接跳至三级。

---

## 二、各模块采集方式与阈值

### 2.1 温湿度（DHT11 x 2）

**采集**：数字接口读取，每 2 秒记录一次温度，计算升温速率（当前温度 - 上次温度）÷ 2（单位 ℃/s）。主循环（100ms）更新温度原始数值。

| 状态 | 环境温度 (℃) | 升温速率 (℃/s) |
|------|-------------|----------------|
| 正常 | < 30 | < 0.5 |
| 一级预警 | 30 ~ 40 | 0.5 ~ 1.0 |
| 二级预警 | 40 ~ 60 | 1.0 ~ 2.5 |
| 三级确认火警 | > 60 | > 2.5 |

**异常处理**：CRC 校验失败 / 通信超时 -> 复用上次有效温度；连续 10 次失败 -> OLED 弹出故障提示 + WiFi 上报传感器故障。

### 2.2 烟雾警报器（MQ-2）

**采集**：ADC 模拟量采样（PC0, ADC 通道 10），范围 0 ~ 4095，主循环每 100ms 读取一次。

| 状态 | 烟雾浓度 ADC 值 |
|------|----------------|
| 正常 | < 200 |
| 一级预警 | 200 ~ 800 |
| 二级预警 | 800 ~ 2000 |
| 三级确认火警 | > 2000 |

### 2.3 火焰传感器（KY-026 x 2）

**采集**：双路 ADC 模拟量（PC1 通道 11, PC2 通道 12），读取双路原始值作为火焰强度。**注：KY-026 有火时 AO 电压降低，值越小火越大。**双路异常偏差时自动剔除，使用剩余一路。

| 状态 | 火焰强度 ADC 值（值越小火焰越大） |
|------|----------------|
| 正常 | ≥ 3000 |
| 一级预警 | 2000 ~ 2999 |
| 二级预警 | 1000 ~ 1999 |
| 三级确认火警 | < 1000 |

### 2.4 光敏传感器（MH）

**采集**：ADC 模拟量（PC3 通道 13），范围 0 ~ 4095，每 100ms 读取。数值越大光照越强。

| 光照状态 | 光敏 ADC 数值 | 含义 |
|----------|-------------|------|
| 白天 | > 800 | 环境自然光充足 |
| 天黑 | <= 800 | 环境光线不足 |

**异常**：连续 10 次数值无变化或超出区间 -> 光敏故障，OLED 提示 + WiFi 上报。

### 2.5 风扇（PB0 TIM3_CH3 PWM）

**限制**：仅室内场景启用。

| 设备状态 | 风扇运行 | PWM 占空比 |
|----------|---------|-----------|
| 无报警 | 停止 | 0% |
| 一级预警 | 低速 | 30% |
| 二级预警 | 中速 | 60% |
| 三级确认火警 | 全速 | 100% |

### 2.6 蜂鸣器（PA4 GPIO）

| 设备状态 | 蜂鸣器模式 |
|----------|-----------|
| 无报警 | 静音关闭 |
| 一级预警 | 每 5 秒断续鸣响 |
| 二级预警 | 每 1 秒断续鸣响 |
| 三级确认火警 | 持续不间断长鸣 |

### 2.7 LED 灯带（WS2812B x 2）

| 设备状态 | 灯带显示 |
|----------|---------|
| 无报警 | 熄灭（天黑时基础白光常亮，见光敏联动） |
| 一级预警 | 黄色闪烁 |
| 二级预警 | 橙色闪烁 |
| 三级确认火警 | 红色高频闪烁 |

### 2.8 水泵（PA1 GPIO -> 继电器 -> 直流水泵）

| 报警等级 | 水泵状态 | 应急说明 |
|----------|---------|---------|
| 正常 / 一级预警 | 停止 | 无明火，禁止喷淋 |
| 二级预警 | 待机预加压 | 开启供水回路预加压，不喷射 |
| 三级确认火警 | 全速持续抽水 | 全开喷淋持续灭火 |

**停机与复位**：
- 自动停机：所有参数回落至正常并稳定 10 秒 -> 断电停机
- 降级停机：三级->二级 -> 抽水切换待机；二级->一级/正常 -> 停机
- 故障保护：水泵继电器持续通电超 30 分钟 -> 自动停机 + WiFi 上报

### 2.9 WiFi 通信（USART2: PA2 TX, PA3 RX）

**上报机制**：
- 常规：每 5 秒上传完整设备数据
- 事件即时：报警等级变化、传感器故障、水泵启停、设备故障 -> 立即推送

**上报数据包字段**：设备编号、时间戳、烟雾浓度、温度、升温速率、火焰红外强度、报警级别、风扇转速、水泵运行状态、WiFi 信号强度

**断连容错**：
- WiFi 断开不影响本地全部功能
- 本地缓存数据，恢复后按时间顺序补传（间隔 30 秒）
- OLED 显示 WiFi 连接/断开图标

## 三、联动判定规则

### 3.1 报警等级触发条件

```
一级预警：
  烟雾达一级 且 火焰未达二级

二级预警：
  烟雾 + 温度 同时达二级
  或 火焰红外达二级

三级确认火警：
  烟雾 + 温度 + 火焰 三项同时达三级
  或 两项严重超标（烟雾 > 2500 且温度 > 55）
```

### 3.2 跨模块联动矩阵

| 报警等级 | 蜂鸣器 | 灯带 | 风扇 | 水泵 |
|----------|--------|------|------|------|
| 正常 | 关 | 天黑白光常亮 / 白天灭 | 停 | 停 |
| 一级 | 5 秒断续 | 黄色闪烁 | 低速 30% | 停 |
| 二级 | 1 秒断续 | 橙色闪烁 | 中速 60% | 待机预加压 |
| 三级 | 持续长鸣 | 红色高频闪烁 | 全速 100% | 全速抽水 |

### 3.3 特殊互斥规则

| 规则 | 条件 | 行为 | 原因 |
|------|------|------|------|
| 风扇助燃防护 | 升温速率达二级且烟雾偏低 | 风扇不启动 | 避免气流助燃 |
| 水泵误喷防护 | 仅升温速率超标、烟雾极低（无明火） | 水泵不启动不预加压 | 防止误喷水 |
| 灯光优先级 | 火情报警触发 | 覆盖光敏天黑照明 | 消防优先 |

**灯光优先级链**：三级火警 > 二级预警 > 一级预警 > 光敏天黑基础照明 > 白天熄灯

## 四、消音逻辑（全模块共用）

按下消音键后进入 15 秒消音倒计时：

| 模块 | 消音期间行为 |
|------|-------------|
| 蜂鸣器 | 关闭 |
| 灯带 | 关闭（但光敏基础照明正常：天黑时白光常亮） |
| 风扇 | 正常运转 |
| 水泵 | 正常运转（不受消音影响） |
| WiFi 上报 | 正常上报 |
| OLED | 正常显示 |
| 传感器采集 | 正常采集 |

**消音解除**：
- 15 秒倒计时结束 + 报警未解除 -> 恢复对应等级声光
- 15 秒倒计时结束 + 报警已解除 -> 保持静音
- **报警升级至三级** -> 立即恢复持续长鸣 + 红色闪烁，**跳过剩余消音时间**

---

## 五、报警降级与解除

- **降级**：全部参数回落至当前等级阈值以下并稳定 10 秒 -> 自动降一级
- **解除**：全部参数回归正常并持续 10 秒 -> 完全解除报警
- 水泵同步跟随报警等级切换状态

---

## 六、通用规则

| 规则 | 说明 |
|------|------|
| 主循环周期 | 100ms |
| 防误报 | 一、二级需连续 3 次采样（6 秒）稳定达标；三级无延时瞬时触发 |
| 系统自检 | 每轮循环末校验 ADC、通信、继电器、水泵回路，异常 WiFi 上报 |
| 看门狗 | 每轮喂狗，防死机 |
| 数据缓存 | 断连时本地缓存，恢复后按时间顺序补传（30 秒间隔） |
