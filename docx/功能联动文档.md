# 功能联动文档

> 以报警等级为主线，串联所有传感器采集阈值、报警等级判定和各模块联动动作
> **标注说明**：`[未实现]` = 设计意图但代码未实现；`[代码实际]` = 与原始设计有差异的实际行为

---

## 一、报警等级定义

| 等级 | 名称 | 触发条件 | 延时 |
|------|------|----------|------|
| 0 | 正常 | 所有参数未达报警阈值 | - |
| 1 | 一级预警 | 任一传感器达一级阈值且无二级及以上 | 连续 3 次采样（约 300ms）稳定确认 |
| 2 | 二级预警 | 烟+温同时达二级 / 任一传感器三级 | 连续 3 次采样（约 300ms）稳定确认 |
| 3 | 三级确认火警 | 烟+温+火三者同时>=二级 / 严重超标 | **即时触发，瞬时联动** |

**严重超标条件**：烟雾 > 3500 且 温度 > 55℃ → 直接三级报警。

---

## 二、各模块采集方式及阈值

### 2.1 温湿度（DHT11 x 2）

**采集**：双路单总线接口（PB14/PB15），每 2 秒读取一次。双路取最高温度值，湿度取首路成功值。计算升温速率（(当前温度 - 上次温度) / 2），内部存储为 ×10 整数（单位 0.1℃/s）。DHT 读取失败时保持上次有效温度，速率置 0。

| 状态 | 环境温度 (℃) | 升温速率 (×10, 0.1℃/s) |
|------|-------------|------------------------|
| 正常 | < 28 | 0 |
| 一级预警 | 28 ~ 31 | ≥ 1（但实际最小非零值为 5 = 0.5℃/s） |
| 二级预警 | 32 ~ 35 | ≥ 2（但实际最小非零值为 5 = 0.5℃/s） |
| 三级确认火警 | ≥ 36 | > 3（即 ≥ 5 = 0.5℃/s） |

> **[代码实际]** 升温速率因整数计算 `delta×5`，rate 值只能是 0 或 5 的倍数（≥5），导致任何温升直接触发 L3 速率报警。阈值 RATE_L1=1/RATE_L2=2/RATE_L3=3 在目前 rate 计算方式下，L1/L2 分级实际上不会触发（非零即 L3）。

**异常处理** `[未实现]`：CRC 校验失败 / 通信超时 -> 不更新有效温度。连续 10 次失败上报传感器故障——代码未实现失败计数和上报。

### 2.2 烟雾浓度传感器（MQ-2）

**采集**：ADC 模拟量输入（PC0, ADC 通道 10），范围 0 ~ 4095。每 100ms 采样一次（4 次平均）。**注：MQ-2 模拟量越浓 AO 电压越高，实测基线 ~1616。**

| 状态 | 烟雾浓度 ADC 值 |
|------|----------------|
| 正常 | < 1700 |
| 一级预警 | 1700 ~ 2499 |
| 二级预警 | 2500 ~ 3000 |
| 三级确认火警 | ≥ 3001 |

### 2.3 火焰传感器（KY-026 x 2）

**采集**：双路 ADC 模拟量输入（PC1 通道 11, PC2 通道 12），独立读取双路原始值作为火焰强度。**注：KY-026 有火时 AO 电压降低，值越小火越大。**双路取最小值（最危险）用于等级判定。

| 状态 | 火焰强度 ADC 值（值越小火焰越大） |
|------|----------------|
| 正常 | ≥ 3000 |
| 一级预警 | 2000 ~ 2999 |
| 二级预警 | 1000 ~ 1999 |
| 三级确认火警 | < 1000 |

### 2.4 光敏传感器（MH）

**采集**：ADC 模拟量输入（PC3 通道 13），范围 400 ~ 4000（400=全亮，4000=全暗）。每 100ms 读取（4 次平均），值越大环境越暗。

| 光照状态 | 光敏 ADC 数值 | 联动动作（仅 L0 正常状态下） |
|----------|-------------|------|
| 天亮 | < 2500 | 灯带关闭 |
| 过渡区 | 2500 ~ 3000 | **保持当前状态**（迟滞回差，避免抖动） |
| 天黑 | > 3000 | 灯带自动开启白光照明 |

> **[代码实际]** 文档原始描述中 400 阈值（LIGHT_BRIGHT）虽已定义但未在 dispatch 逻辑中使用。实际迟滞仅用 LIGHT_DARK=3000（开灯阈值）和 LIGHT_OFF=2500（关灯阈值），中间 2500~3000 区间维持原状态不变。

### 2.5 风扇（PB0 TIM3_CH3 PWM）

**控制**：根据报警等级自动调速。

| 设备状态 | 风扇转速 | PWM 占空比 |
|----------|---------|-----------|
| 无报警 | 停止 | 0% |
| 一级预警 | 低速 | 30% |
| 二级预警 | 中速 | 60% |
| 三级确认火警 | 全速 | 100% |

### 2.6 蜂鸣器（PA4 GPIO，低电平有效）

| 设备状态 | 蜂鸣器模式 |
|----------|-----------|
| 无报警 | 静默关闭 |
| 一级预警 | 每 5 秒 toggle 一次（半周期 2.5s 开/关） |
| 二级预警 | 每 1 秒 toggle 一次（半周期 0.5s 开/关） |
| 三级确认火警 | 持续长鸣不中断 |

### 2.7 LED 灯带（WS2812B x 2：PC12/DIN1 + PC11/DIN2）

| 设备状态 | 灯带显示 | 闪烁周期 |
|----------|---------|---------|
| 无报警 | 光敏自动控制（天黑 >3000 开白光，<2500 关，2500~3000 迟滞保持） | 常亮 |
| 一级预警 | 绿色闪烁（50% 亮度） | ~500ms toggle（~1s 完整周期） |
| 二级预警 | 蓝色闪烁（50% 亮度） | ~500ms toggle（~1s 完整周期） |
| 三级确认火警 | 红色高频闪烁（50% 亮度） | ~100ms toggle（~200ms 完整周期） |

### 2.8 水泵（PA1 GPIO -> 继电器 -> 直流水泵，低电平有效）

| 报警等级 | 水泵状态 | 说明 |
|----------|---------|------|
| 正常 / 一级 / 二级 | 维持当前状态 | 不主动干预，也不主动关闭 |
| 三级确认火警 | 开启 | 全开喷淋持续灭火 |

**停止与复位**：
- 自动停止：报警降级至正常（L0）后自动关闭水泵；L1/L2 期间维持当前状态不主动干预
- 手动停止：通过 view 层手动控制或全局关机
- 故障保护 `[未实现]`：水泵继电器连续通电超 30 分钟自动停止——代码无超时计时

### 2.9 WiFi 通信

> **[已移除]** WiFi 模块（USART2: PA2 ANTHROPIC, PA3 RX）的 `wifi.c` / `wifi.h` 已从项目中删除。`main.c` 中无 WiFi 初始化或引用。当前项目仅使用 USART1（PA9/PA10）输出调试日志。所有 WiFi 上报、断线缓存、传感器异常上报等功能均已移除。

## 三、联动逻辑

### 3.1 报警等级判定规则

```
一级预警：
  任一传感器一级 且 无二级及以上

二级预警：
  烟 + 温 同时达二级
  或 任一传感器三级

三级确认火警：
  烟 + 温 + 火 三者同时达二级
  或 严重超标（烟雾 > 3500 且 温度 > 55℃）
```

> 温度等级 = max(温度阈值等级, 升温速率等级)；双路火焰取最小值（最危险）判定；DHT 读取无效时温度等级强制归 0。

### 3.2 各模块联动动作

| 报警等级 | 蜂鸣器 | 灯带 | 风扇 | 水泵 |
|----------|--------|------|------|------|
| 正常 | 关 | 光敏自动（带迟滞） | 停 | 维持（不主动关） |
| 一级 | 5s 间隔 toggle | 绿色闪烁 | 低速 30% | 维持 |
| 二级 | 1s 间隔 toggle | 蓝色闪烁 | 中速 60% | 维持 |
| 三级 | 持续长鸣 | 红色高频闪烁 | 全速 100% | 开启 |

### 3.3 防冲突互锁

| 冲突 | 条件 | 行为 | 原因 |
|------|------|------|------|
| 风扇与报警等级 | 多传感器数据偏差异常 | 风扇不降级 | 以最高报警等级为准 |
| 水泵与灭火 | 火焰传感器异常、烟雾未消 | 水泵不关闭或预加压 | 防止复燃淹水 |
| 灯光与报警等级 | 高级报警触发时 | 覆盖光敏自动控制 | 报警优先 |

**灯光优先级**：三级报警 > 二级预警 > 一级预警 > 光敏自动控制 > 手动关闭

## 四、静音逻辑（全模块共用）

静音触发后保持 15 秒（1500 tick × 10ms），可续计时。

| 模块 | 静音期间行为 |
|------|-------------|
| 蜂鸣器 | 关闭（包括 L3 级别） |
| 灯带 | 关闭（若报警未解除且静音到期，恢复对应等级闪烁） |
| 风扇 | 继续运转 |
| 水泵 | 继续运转（不受静音影响） |
| 传感器采集 | 继续采集 |

**静音恢复**：
- 15 秒倒计时结束 + 报警未解除 -> 恢复对应等级联动
- 15 秒倒计时结束 + 报警已解除 -> 保持静默
- ~~期间报警等级升级 -> 强制恢复报警声 + 红色闪烁，无视剩余静音时间~~ **[未实现]**：代码中静音期间 beep 和灯带完全关闭，即使升级到 L3 也不会恢复。`alarm_drive_beep()` 中 `mute_flag` 直接屏蔽所有 beep 输出，`alarm_dispatch_actuators()` 中 `mute_flag` 屏蔽灯带更新。

## 五、升降级与恢复

- **升级**：目标等级高于当前等级时，L1/L2 每 10 秒（100 tick × 100ms）自动升一级
- **降级**：目标等级回落到低等级以下稳定 10 秒 -> 逐步降级（每次降一级，间隔 10 秒）
  - L3→L2：10 秒；L2→L1：10 秒；L1→Normal：10 秒
- 水泵：L3 时开启，降级至 L1/L2 时维持当前状态，降级至正常（L0）时自动关闭

## 六、通用规则

| 项目 | 说明 |
|------|------|
| 主循环周期 | 10ms（100Hz） |
| 传感器采样 | ADC（烟雾/火焰/光敏）每 100ms；DHT 每 2s |
| 报警判定 | 每 100ms 评估一次目标等级并执行稳定/升级/降级逻辑 |
| 防抖 | L1/L2 需连续 3 次采样（约 300ms）稳定达标；L3 即时触发 |
| 看门狗 `[未实现]` | 代码中无 IWDG/WWDG 初始化或喂狗 |
| 系统自检 `[未实现]` | 无 ADC/通信/继电器回路自检逻辑 |
| 数据缓存 `[已移除]` | WiFi 模块已删除，无断线缓存/补发功能 |
