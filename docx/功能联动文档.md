# 功能联动文档

> 以报警等级为主线，串联所有传感器采集阈值、报警等级判定和各模块联动动作

---

## 一、报警等级定义

| 等级 | 名称 | 触发条件 | 延时 |
|------|------|----------|------|
| 0 | 正常 | 所有参数未达报警阈值 | - |
| 1 | 一级预警 | 任一传感器达一级阈值 | 连续 3 次（约6 秒）稳定确认 |
| 2 | 二级预警 | 烟+温同时达二级 / 任一传感器三级 | 连续 3 次（约6 秒）稳定确认 |
| 3 | 三级确认火警 | 烟+温+火三者同时>=二级 / 严重超标 | **即时触发，瞬时联动** |

**严重超标条件**：烟雾 > 3500 且 温度 > 55℃ → 直接三级报警。

---

## 二、各模块采集方式及阈值

### 2.1 温湿度（DHT11 x 2）

**采集**：单总线接口读取，每 2 秒记录一次温度，计算升温速率（(当前温度 - 上次温度) / 2），单位 ℃/s。主循环每 100ms 更新温度原始缓存值。

| 状态 | 环境温度 (℃) | 升温速率 (℃/s) |
|------|-------------|----------------|
| 正常 | < 32 | < 0.1 |
| 一级预警 | 32 ~ 35 | 0.1 ~ 0.2 |
| 二级预警 | 35 ~ 37 | 0.2 ~ 0.3 |
| 三级确认火警 | > 37 | > 0.3 |

**异常处理**：CRC 校验失败 / 通信超时 -> 不更新有效温度，连续 10 次失败 -> OLED 显示传感器故障 + WiFi 上报"传感器异常"。

### 2.2 烟雾浓度传感器（MQ-2）

**采集**：ADC 模拟量输入（PC0, ADC 通道 10），范围 0 ~ 4095。主循环每 100ms 读取一次。**注：MQ-2 模拟量越浓 AO 电压越高，实测基线 ~1616。**

| 状态 | 烟雾浓度 ADC 值（值越大浓度越浓） |
|------|----------------|
| 正常 | < 1700 |
| 一级预警 | 1700 ~ 2499 |
| 二级预警 | 2500 ~ 3000 |
| 三级确认火警 | > 3000 |

### 2.3 火焰传感器（KY-026 x 2）

**采集**：双路 ADC 模拟量输入（PC1 通道 11, PC2 通道 12），独立读取双路原始值作为火焰强度。**注：KY-026 有火时 AO 电压降低，值越小火越大。**双路异常偏差时自动剔除，使用剩余一路。

| 状态 | 火焰强度 ADC 值（值越小火焰越大） |
|------|----------------|
| 正常 | ≥ 3000 |
| 一级预警 | 2000 ~ 2999 |
| 二级预警 | 1000 ~ 1999 |
| 三级确认火警 | < 1000 |

### 2.4 光敏传感器（MH）

**采集**：ADC 模拟量输入（PC3 通道 13），范围 400 ~ 4000（400=全亮，4000=全暗）。每 100ms 读取，值越大环境越暗。

| 光照状态 | 光敏 ADC 数值 | 联动动作（仅 L0 正常状态下） |
|----------|-------------|------|
| 强光 | ≤ 400 | 灯带关闭 |
| 常亮 | 400 ~ 3000 | 灯带关闭（环境光充足） |
| 天黑 | > 3000 | 灯带自动开启白光照明 |

### 2.5 风扇（PB0 TIM3_CH3 PWM）

**控制**：根据报警等级自动调速。

| 设备状态 | 风扇转速 | PWM 占空比 |
|----------|---------|-----------|
| 无报警 | 停止 | 0% |
| 一级预警 | 低速 | 30% |
| 二级预警 | 中速 | 60% |
| 三级确认火警 | 全速 | 100% |

### 2.6 蜂鸣器（PA4 GPIO）

| 设备状态 | 蜂鸣器模式 |
|----------|-----------|
| 无报警 | 静默关闭 |
| 一级预警 | 每 5 秒鸣叫一次 |
| 二级预警 | 每 1 秒鸣叫一次 |
| 三级确认火警 | 持续长鸣不中断 |

### 2.7 LED 灯带（WS2812B x 2）

| 设备状态 | 灯带显示 |
|----------|---------|
| 无报警 | 光敏自动控制（天黑 >3000 开白光照明，否则关闭） |
| 一级预警 | 绿色闪烁 |
| 二级预警 | 蓝色闪烁 |
| 三级确认火警 | 红色高频闪烁 |

### 2.8 水泵（PA1 GPIO -> 继电器 -> 直流水泵）

| 报警等级 | 水泵状态 | 应急说明 |
|----------|---------|---------|
| 正常 / 一级 / 二级 | 维持当前状态 | 不主动干预 |
| 三级确认火警 | 全速持续抽水 | 全开喷淋持续灭火 |

**停止与复位**：
- 自动停止：所有传感器恢复正常稳定 10 秒 -> 逐级降级
- 手动停止：右摇杆 -> 关机 -> 水泵断电（全局关机时强制关闭）
- 故障保护：水泵继电器连续通电超 30 分钟 -> 自动停止 + WiFi 上报

### 2.9 WiFi 通信（USART2: PA2 TX, PA3 RX）

**上报策略**：
- 常规：每秒上传全量设备数据
- 事件即时：报警等级变化、传感器异常、水泵启停等事件 -> 即时上报

**上报数据包含字段**：报警等级、烟雾浓度、温度、升温速率、火焰强度、光敏值、风扇转速、水泵状态、蜂鸣器状态、灯带状态

**断线容错**：
- WiFi 断开不影响本地安全功能
- 本地缓存数据，恢复后即时补发
- OLED 显示 WiFi 连接/断开图标

## 三、联动逻辑

### 3.1 报警等级判定规则

```
一级预警：
  任一传感器一级 且 无二级及以上

二级预警：
  烟 + 温 同时达二级
  或 任一传感器三级

三级确认火警：
  烟 + 温 + 火 三者同时达二级
  或 严重超标（烟雾 > 3500 且 温度 > 55℃）
```

### 3.2 各模块联动动作

| 报警等级 | 蜂鸣器 | 灯带 | 风扇 | 水泵 |
|----------|--------|------|------|------|
| 正常 | 关 | 光敏自动 | 停 | 维持 |
| 一级 | 5 秒间隔 | 绿色闪烁 | 低速 30% | 维持 |
| 二级 | 1 秒间隔 | 蓝色闪烁 | 中速 60% | 维持 |
| 三级 | 持续长鸣 | 红色高频闪烁 | 全速 100% | 全速抽水 |

### 3.3 防冲突互锁

| 冲突 | 条件 | 行为 | 原因 |
|------|------|------|------|
| 风扇与报警等级 | 多个传感器数据偏差异常 | 风扇不降级 | 以最高报警等级为准 |
| 水泵与灭火 | 火焰传感器异常、烟雾未消 | 水泵不关闭或预加压 | 防止复燃淹水 |
| 灯光与报警等级 | 高级报警触发时 | 覆盖光敏自动控制 | 报警优先 |

**灯光优先级**：三级报警 > 二级预警 > 一级预警 > 光敏自动控制 > 手动关闭

## 四、静音逻辑（全模块共用）

静音触发后保持 15 秒，可续计时。

| 模块 | 静音期间行为 |
|------|-------------|
| 蜂鸣器 | 关闭 |
| 灯带 | 关闭（若报警未解除且静音到期，恢复对应等级闪烁） |
| 风扇 | 继续运转 |
| 水泵 | 继续运转（不受静音影响） |
| WiFi 上报 | 继续上报 |
| OLED | 正常显示 |
| 传感器采集 | 继续采集 |

**静音恢复**：
- 15 秒倒计时结束 + 报警未解除 -> 恢复对应等级联动
- 15 秒倒计时结束 + 报警已解除 -> 保持静默
- **期间报警等级升级** -> 强制恢复报警声 + 红色闪烁，**无视剩余静音时间**

---

## 五、升降级与恢复

- **升级**：全部传感器在最高等级阈值以上，每 10 秒自动升一级
- **降级**：全部传感器回落到低等级阈值以下稳定 10 秒 -> 逐步降级
- 水泵同步跟随报警等级切换状态

---

## 六、通用规则

| 项目 | 说明 |
|------|------|
| 主循环周期 | 10ms（100Hz） |
| 防抖 | 低等级报警需连续 3 次（约6 秒）稳定达标；三级报警即时触发 |
| 系统自检 | 每循环周期末校验 ADC、通信、继电器/水泵回路，异常 WiFi 上报 |
| 看门狗 | 每循环周期喂狗一次 |
| 数据缓存 | 断线时本地缓存，恢复后按时间顺序补发（30 分钟内） |
